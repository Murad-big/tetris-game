# Тетрис в браузере

Учебный проект для университета: классический тетрис на JavaScript и Canvas. Работает прямо в браузере, без сервера и установки зависимостей.

## Как играть

Скачайте репозиторий и откройте `index.html`. Партия начинается сразу.

| Клавиша | Действие |
| --- | --- |
| ← / → | Переместить фигуру |
| ↑ | Повернуть |
| ↓ | Опустить на одну клетку |
| Пробел | Сразу опустить до упора |

После окончания партии нажмите `Restart`, чтобы начать заново.

## Возможности

- Подсчёт очков за заполненные линии.
- Повышение уровня и скорости игры.
- Предпросмотр следующей фигуры.
- Повторный запуск после окончания партии.

## Файлы

- `index.html` — страница игры.
- `css/` — оформление.
- `src/` — игровая логика, фигуры и отрисовка.
- `dist/tetris.js` — готовый скрипт, подключённый на странице.

Управление рассчитано на клавиатуру. Если меняете код в `src/`, учитывайте, что страница использует файл из `dist/`; автоматическая сборка в репозитории не настроена.
